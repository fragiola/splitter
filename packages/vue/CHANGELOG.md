# @fragiola/splitter-vue

## 0.1.0

### Minor Changes

- [#16](https://github.com/fragiola/splitter/pull/16) [`0537b5e`](https://github.com/fragiola/splitter/commit/0537b5e840d2d9ea9351bf7017015fca6ff8b83e) Thanks [@maurodesouza](https://github.com/maurodesouza)! - First release. `@fragiola/splitter-vue` is the Vue 3.5 adapter: the unstyled `Splitter.Group`, `Splitter.Panel` and `Splitter.Separator` primitives (nested groups, `as` and the `render` slot to swap an element, `v-model:layout` and `@layout-commit`, state as `data-*` and ARIA), `typedSplitter<Types>()` for the registry's ids in templates, the composables (`useGroup`, `usePanel`, `useSeparator`, `useSplitter`, `useSplitterRef`, `useSplitterState`), and the whole core re-exported, so a Vue app installs this one package.
