# @fragiola/splitter-angular

## 0.1.0

### Minor Changes

- [#17](https://github.com/fragiola/splitter/pull/17) [`394c6f3`](https://github.com/fragiola/splitter/commit/394c6f33a7f0753d33549d62b47caac26c3bf20f) Thanks [@maurodesouza](https://github.com/maurodesouza)! - First release. `@fragiola/splitter-angular` is the Angular 22 adapter: standalone, signal-based, zoneless attribute directives on your own elements (`splitterGroup`, `splitterPanel`, `splitterSeparator`, all in `SPLITTER`), with nested groups, `[(layout)]` and `(layoutCommit)`, the panel's `(resize)`, `(collapse)` and `(expand)`, state as `data-*` and ARIA, the injection functions (`injectGroup`, `injectPanel`, `injectSeparator`, `injectSplitter`, `injectSplitterState`), and the whole core re-exported, so an Angular app installs this one package. Built by ng-packagr (Angular Package Format, partial compilation, ESM only).
