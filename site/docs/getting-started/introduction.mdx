title: Introduction
description: What the package does for a split view (resizing, the keyboard, collapsing, a saved layout) and what stays yours, down to every pixel, cursor and word.
---

A split view puts panels side by side, or stacks them, with a separator between each pair that
the user drags to share the room. `@fragiola/splitter-react` and `@fragiola/splitter-vue` give you that
behaviour as three headless primitives, `Splitter.Group`, `Splitter.Panel` and `Splitter.Separator`, over a
framework-free core, `@fragiola/splitter`; `@fragiola/splitter-angular` gives it as three directives on
your own elements.

What the package gives you:

- **Resizing** with the pointer (mouse, touch and pen through one path, with pointer capture),
  with the keyboard (the WAI-ARIA APG Window Splitter pattern), and from code.
- **Constraints** on every panel: a minimum, a maximum, a default size, in `%`, `px`, `em`,
  `rem`, `vh` or `vw`.
- **Collapsing**: a collapsible panel snaps shut past a threshold and remembers the size it
  returns to.
- **Nested groups** that share one model, so one JSON document saves the whole layout.
- **A typed model** whose every change is a command that middleware can veto or rewrite, and a
  JSON Schema for each command, ready for automation.
- **Right-to-left** as a mirror, and server rendering without a layout shift.

What stays **yours**: every pixel. The package ships no CSS, no icons, no cursors and no text.
It writes only the structural inline style (the flex sizing of the panels) and exposes its state
as `data-*` attributes and ARIA, so Tailwind, plain CSS, CSS modules or CSS-in-JS all work.
Accessible names come from you too: a separator has no label until you give it one.

<Framework name="react">

```tsx title="editor-layout.tsx"
import { Splitter } from "@fragiola/splitter-react";

export function EditorLayout() {
    return (
        <Splitter.Group className="h-96">
            <Splitter.Panel id="files" defaultSize="25%" minSize="10%">
                Files
            </Splitter.Panel>
            <Splitter.Separator aria-label="Resize files" className="w-1 bg-gray-300" />
            <Splitter.Panel id="editor">Editor</Splitter.Panel>
        </Splitter.Group>
    );
}
```

</Framework>

import { Component } from "@angular/core";

The behaviour follows [React Resizable Panels](https://github.com/bvaughn/react-resizable-panels)
(its flex groups): the same constraints, units, collapse thresholds and restore sizes. The model,
the commands and the primitives are Fragiola's, shared with every library of the ecosystem.
