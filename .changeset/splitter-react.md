First release. `@fragiola/splitter-react` is the React 19 adapter: the unstyled `Splitter.Group`, `Splitter.Panel` and `Splitter.Separator` primitives (nested groups, `render` to swap an element, state as `data-*` and ARIA), the hooks (`useGroup`, `usePanel`, `useSeparator`, `useSplitter`, `useSplitterRef`, `useSplitterState`), and the whole core re-exported, so a React app installs this one package.
