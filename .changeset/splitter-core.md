First release. `@fragiola/splitter` is the framework-free core: the pure layout rules and units (percent, pixels, `em`, `rem`, `vh`, `vw`), a typed model whose every change is a command through a bus with middleware and events (`run`, `can`, `check`, `get`, `is`), a JSON v1 document with its JSON Schema and validator, and the engine that binds a group to the DOM: measurement, pointer drags, the Window Splitter keyboard, right-to-left, collapse, constraints and ARIA values. Zero runtime dependencies.
