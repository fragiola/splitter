First release. `@fragiola/splitter-angular` is the Angular 22 adapter: standalone, signal-based, zoneless attribute directives on your own elements (`splitterGroup`, `splitterPanel`, `splitterSeparator`, all in `SPLITTER`), with nested groups, `[(layout)]` and `(layoutCommit)`, the panel's `(resize)`, `(collapse)` and `(expand)`, state as `data-*` and ARIA, the injection functions (`injectGroup`, `injectPanel`, `injectSeparator`, `injectSplitter`, `injectSplitterState`), and the whole core re-exported, so an Angular app installs this one package. Built by ng-packagr (Angular Package Format, partial compilation, ESM only).
